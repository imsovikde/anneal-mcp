# Changelog

All notable changes to the Anneal Model Context Protocol (MCP) server integration and manifests are documented in this file.

## [1.2.6] - 2026-09-11

### Added
- Official manifest support for the Linux Foundation MCP Registry (`server.json`).
- Smithery.ai remote connector configuration (`smithery.yaml`).
- Google Gemini CLI / Spark extension packaging (`gemini-extension.json`).
- Direct 1-click installation deep-links for Claude.ai and ChatGPT.
- Strict Cross-Origin-Resource-Policy and CORS configuration for `/mcp-logo.svg`.
